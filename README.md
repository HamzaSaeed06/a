# Full-Stack Monorepo (MERN + Flutter)

Welcome to the central repository for the project. This repository contains the backend API server, the React web application, and the Flutter multi-platform application.

---

## Repository Structure

```text
.
├── backend/          # Express.js REST API & Database Models
├── frontend/         # React.js Web Application
├── mobile-app/       # Flutter Cross-Platform Client (Android, iOS, Web)
├── .gitignore        # Global Git ignore rules
└── README.md         # Project documentation & setup instructions
```

---

## Tech Stack

- **Backend:** Node.js, Express.js, MongoDB / Mongoose, JWT Authentication
- **Frontend (Web):** React.js, Vite, Axios / Fetch API
- **Mobile App:** Flutter, Dart, Provider / Riverpod / Bloc, Http / Dio
